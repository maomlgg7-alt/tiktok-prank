# TikTok Prank App 🎭

واجهة تحاكي TikTok للمزح والترفيه — مبنية بـ React + Vite + Tailwind CSS.

## 🚀 تشغيل المشروع

```bash
# 1. تثبيت المكتبات
npm install

# 2. تشغيل السيرفر المحلي
npm run dev

# 3. فتح المتصفح على
http://localhost:5173
```

## 🏗️ البناء للنشر

```bash
npm run build
```

## 📱 المميزات

### الملف الشخصي
- اضغط على أي نص لتعديله (الاسم، البايو، الأرقام)
- اضغط على الصورة لرفع صورتك
- اضغط على خانات الفيديو لرفع صور/مقاطع

### الرسائل
- زر `+ محادثة` لإنشاء محادثة جديدة
- اختر **مُرسَل** أو **مُستلَم** قبل الإرسال
- اضغط على اسم/صورة المستخدم لتعديلها

### البث المباشر 🔴
- زر الـ FAB الأحمر في الزاوية لفتح/إغلاق البث
- اضغط على عداد المشاهدين لتعديله
- زر ▶ لتشغيل التعليقات التلقائية
- زر 👤 لإضافة "انضم للبث" يدوياً
- `📷 تغيير الخلفية` لرفع صورة أو فيديو

## 💾 التخزين
كل البيانات تُحفظ تلقائياً في **localStorage** — تبقى حتى بعد إغلاق المتصفح.
